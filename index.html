ss -planet decoder

Paste the output of sudo ss -planet to see which ports are open, where they are bound and which program owns them. Everything is processed in your browser — nothing is uploaded.

Tip: run it with sudo so process names and PIDs are included.
Optional: resolve UIDs to user names

Paste the output of getent passwd (or /etc/passwd) so that uid:102 is shown as a user name.
